## Explicit root rulings incorporated

**Source-compatible status:** after every original owner has an eligible settled native endpoint, exact history/provider evidence and all privacy/source gates, `status='completed'` denotes measured owner-schedule completion only. Mandatory `driver_status='owner_schedule_completed'`, `measurement_validity` and original native outcomes retain error/length/max-turn results. Actual assistant output remains unchanged, including empty output. Task success comes solely from unchanged official utility. Source export/evaluation uses a pending measurement stage so the original final-answer fallback can inspect actual text; failed source/profile checks revert final status to error and never pass receipt admission. Historical partial cases are not rewritten, copied or spliced.

**Actual backend metadata:** shared `target_config` supplies existing native API fields `context_window=32768` and `model_max_tokens=4096` to every new H0/RSI case. This corrects unknown-model fallbacks128000/16384; `llm.max_tokens=4096` alone does not correct those limits. Entry verifies the selected loop's actual `model_limits` result and records its actual compaction settings. Enabled/reserveTokens/keepRecentTokens/resources and original compaction policy are not overridden. This is a declared compatibility change in the NEW matched profile, not equivalence to old strict runs or proof that Pi's estimator matches Qwen tokenization.

**All-call summary observation:** the initially identified summary hook gap was repaired under root authorization. A case-local wrapper around the selected loop's actual `_provider_call` observes the original arguments/context and original `build_openai_payload` normalization for both agent and summary calls, then awaits the original callable once with exactly the original arguments/callback/cancellation objects. It returns the original result or exception and restores the original function on exit. Vendor/Snapshot source bytes and model/tool loop behavior are unchanged. No key/environment/header object is recorded. The callable's actual source path/hash/line/signature is bound to the selected Snapshot runtime map. All wire requests must reconcile; unknown/incompatible APIs or projections remain invalid. Agent and summary counts are separately retained, without treating summary calls as extra agent-turn allowance.
