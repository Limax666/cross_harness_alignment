Preserve structured failure reasons, distinguish schema/model failures for the protocol cost from source execution/infrastructure failures, and inspect source receipts before admitting metrics. Validate the public schema before dispatch so invalid arguments cannot execute merely because the source backend itself only checks selected routing arguments. This is a backend contract issue; no claim is made that the unfinished outer runtime already dispatches malformed calls.

4. **Important — pinned revision checks can certify modified source/checker bytes as official.** `scripts/hsrl_v3/pool.py:195–206,210–211` verifies only Git HEAD, then records hashes of the current working tree. A modified SkillLife grader/executor, or modified ClawGym `reward/check.py`, leaves HEAD unchanged and becomes the newly accepted baseline. Later `checked_source`/`source_code_hashes` comparisons therefore accept the modification, while provenance claims the pinned official revision and unmodified executor/checker. Compare all consumed source/code/checker/input bytes to the pinned commit (including unexpected files), or explicitly bind a separately reviewed adaptation diff; reject unexplained pre-preparation drift before recording the manifest.

5. **Important — the frozen holdout assignment is not actually bound or enforced during pool preparation.** `scripts/hsrl_v3/pool.py:199–205,227–238` binds the source manifest and task metadata but trusts each mutable split label. A changed row can cross its template into train, or an entire test template can move into train, and preparation still succeeds. `pool.py:256–257` merely records the new split-file hash and copies declared counts. The tests compare labels against that same file; only aggregate/template checks offer partial protection and are not admission checks. Pin the reviewed split artifact digest or validate the specified deterministic template-to-split assignment, then enforce whole-template/parent grouping, B/D/E 2/1/1 allocations, 6/3/3 template counts, and paired-condition counts before writing any admitted pool.
