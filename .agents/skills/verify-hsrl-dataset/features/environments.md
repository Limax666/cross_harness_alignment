# Consume real isolated task environments

The same admitted task and environment result feed GRPO and CHS-PO. Policy input
contains only public messages/tools; private bundles, rules and controls remain
in the collector.

## Sub-features

- Public rendering and immutable relocated source assets.
- Real tool call/state changes, source grading and independent reset.
- Unavailable-cost and malicious-utility masks, invalid-episode rejection.
- 875 balanced blocks with G8 and same-task K2 on successive configurations.

## How to get to it (user POV)

Use `Dataset.public`, `Dataset.episode`, `Dataset.sampler.step`,
`Dataset.grpo_reward` and `Dataset.chspo_components` in the usage document.

## Driving it with the Dataset API

Preconditions: normal mode requires a truly published release; the explicitly
nontraining `Dataset.for_verification(candidate)` is available for candidate
audits. Use the artifact's `code/` in a fresh process and unique evidence paths.

Follow the usage document's context-managed episode recipe with an actual
selected source task and its advertised actions. Observe genuine state/history,
raw private grades, output files and reset. Do not solve invented tasks or use
fabricated model rollouts. Audit the full real sampler identity pass. Verify
malicious-query utility is null/PG-masked, unsupported harm/judge/persistence
costs are null/false-masked and invalid episodes raise rather than become zero.
For pooled QC, inspect actual distinct source-child PIDs/nonces, source/snapshot
hashes and exact-container cleanup before accepting completion.

## Gotchas

Claw reward is the pinned official code-verifier component. AgentDoG cost is a
registered tool-call rule, not actual harm/ASR. Do not render collector extra_info
or quality controls into actor prompts. Initial context checks do not establish
C1/C2 long-history collector behavior or a successful optimizer update.
